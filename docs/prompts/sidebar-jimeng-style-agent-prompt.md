# 即梦式固定窄栏改造提示词

你正在维护 EnovaMotion（灵动创影）单一新架构 monorepo。请只修改 `apps/web` 中的应用壳层和样式，实现类似即梦的左侧固定窄栏导航。

## 目标

- 左侧导航始终保持窄栏，宽度约 68px；桌面端和移动端都不能展开成文字侧栏。
- 只展示品牌 Logo、导航图标、余额图标、用户头像和退出图标；文字通过 `title` 或无障碍标签提供提示。
- 去掉侧边栏展开/收起按钮、二级菜单展开交互、移动端打开大侧栏的入口和遮罩层。
- 生成图片、生成视频、资产、设置等现有入口必须继续可用，当前路由的图标状态必须正确高亮。
- 管理员入口、自定义菜单、文档链接、余额跳转、退出登录和语言切换不能被破坏。
- 主内容区应自动占据剩余空间，不因窄栏出现横向滚动或布局跳动。

## 视觉要求

- 白色侧栏，右侧 1px 浅灰分隔线，整体轻量、克制，接近即梦左侧导航。
- 图标垂直排列，单项约 44–52px 高，激活项使用浅青绿色圆角背景和品牌色图标。
- Logo 居中；导航与底部账户区域留出均匀间距。
- 不引入新的 UI 库，不重做主内容页面，不修改 API、数据库、队列、计费或权限逻辑。

## 实施约束

- 先阅读 `docs/README.md`、`docs/product-reference.md` 和 `AGENTS.md`。
- 优先修改 `apps/web/app/[locale]/app/AppShell.tsx` 与 `apps/web/app/globals.css`；保持 Next.js App Router、Tailwind、Ant Design 和现有组件风格。
- 不删除任何已有路由，只改变导航呈现方式。
- 保留 `title`、`aria-label` 或屏幕阅读器文本，确保图标-only 导航可访问。
- 完成后运行 `pnpm --filter @enova/web lint`、`pnpm --filter @enova/web typecheck` 和 `pnpm --filter @enova/web test`，报告实际结果；不要把未运行的命令写成通过。

## 验收标准

1. `/app/images`、`/app/videos`、`/app/assets`、`/app/settings` 和管理员页面均能从图标导航访问。
2. 任意页面刷新或切换路由后侧栏始终为窄栏，不出现文字导航或可展开的大侧栏。
3. 当前入口仍有清晰的激活态，余额和退出登录仍可点击。
4. 900px 以下窗口不出现遮罩层、抽屉式展开或内容横向溢出。
